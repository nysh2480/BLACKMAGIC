PROJECT

Bundles GRAPHIC (palette/sprites/map/movie) + SOUND (waves/notes/tracks/master) + GAME (items/entities/scenario) + the CUI program into one JSON blob, so the whole app can be saved, shared, and reloaded as a single integrated project.
GENERATE OPEN WORLD: 64x64 open field (CLAY/GRASS/GLASS floors, SKY ceiling) with scattered huts, rocks and ivy walls — not room/corridor dungeons. GENERATE SCENARIO SET remains the dungeon quest layout (stone floor, dark ceiling, 2x2 areas).
GENERATE SCENARIO SET builds the full 64x64 map and splits it 2x2 into four 32x32 areas: three MESO areas (a landmark plus three MICRO event sites spread around it) and one MACRO area holding the final trial, a boss fight or a three-seal puzzle. Each landmark carries its own organisation / role / tension axis; the 13 quests' requirements are typed ITEM / INFO / ALLY; the ITEM, CHARACTER and boss ENEMY records they name are created for you; and a ready-to-RUN program (one EVENT per quest, each waiting on its own zone) is written into the CUI code box. Two of the three MESO areas open the final gate, all three open it at full strength. Walls are textured by landmark type -- STONE (ashlar) for CHURCH, TORCH (lit sconce) for CASTLE/FORT, CRACKED for CATACOMB/RUIN/GRAVEYARD, WATER (wet stone) for CLIFF/RIVER, BRICK for TOWN/SCHOOL, MUD (earth brick) for VILLAGE, WOOD (planks) for PORT/FOREST/BEACH -- so structures read clearly against the floor instead of blending into one flat gray. Same SEED, same world.
