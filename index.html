BLACKMAGIC EFFECTS仕様（v119）

STATEはオブジェクトの基本実行状態、EFFECTSは状態異常・強化・弱体化などの付帯効果として分離管理する。

1. 基本方針

  • STATE：FREE、ACTIVE、HURT、DEADなど、オブジェクトが現在どの基本動作状態にあるかを表す。
  • EFFECTS：POISON、PARALYZE、REGEN、HASTE、SLOW、SHIELDなどを複数同時に保持できる。
  • 効果が存在しても、オブジェクトのSTATEをABNORMALへ固定しない。
  • 麻痺・拘束などの行動制約は、EFFECTSを参照して移動・攻撃などの開始条件を制限する。

2. 効果スロット

オブジェクトごとに固定長の効果スロットを割り当て、SoA配列で管理する。現在の最大値は1オブジェクトあたり8効果。

  • EFFECT_ID：効果種別
  • EFFECT_FLAGS：効果の処理モードなどのフラグ
  • EFFECT_VALUE：効果量
  • EFFECT_STACK：重複・スタック数
  • EFFECT_COUNT：残り回数
  • EFFECT_INTERVAL：定期処理間隔（performance.now()基準のミリ秒）
  • EFFECT_NEXT：次回処理時刻
  • EFFECT_END：効果終了時刻
  • EFFECT_SOURCE：効果を付与した発生源ID

3. 現在の効果ID

NONE=0、POISON=1、PARALYZE=2、REGEN=3、HASTE=4、SLOW=5、SHIELD=6。

現時点で定期処理が実装されているのはPOISONとREGEN。その他は登録・保持の基盤であり、行動制約や数値補正は今後の実装対象。

4. 内部API

  • EFFECT_INDEX(objectId, slot)：オブジェクトとスロットから配列位置を取得
  • _ADD_EFFECT(...)：効果を追加または既存効果へ適用
  • _REMOVE_EFFECT(objectId, effectId)：指定効果を削除
  • _HAS_EFFECT(objectId, effectId)：効果の有無を確認
  • _PROCESS_EFFECTS(objectId, now)：効果の時間経過と定期処理を実行
  • _CLEAR_OBJECT_EFFECTS(objectId)：オブジェクトの全効果を消去

5. MAGICコマンド

EFFECT ID, EFFECT_ID, VALUE, COUNT, INTERVAL, DURATION
REMOVE_EFFECT ID, EFFECT_ID

EFFECTのINTERVALとDURATIONは現在ミリ秒として扱う。EFFECT_IDは数値で指定する形式を基本とする。

6. ライフサイクル

  • SPAWN_ENTITY時に対象の効果を初期化する。
  • REVIVE_ENTITY時に対象の効果を初期化する。
  • 更新ループ内でプレイヤーおよび各エンティティの効果を処理する。
  • ゲームリセット時にEFFECT_USEDを初期化する。

7. 未実装・注意事項

  • PARALYZE、HASTE、SLOW、SHIELDの具体的なゲーム効果は未実装。
  • 遅延フレームに対して定期処理を複数回追いつかせる処理は未実装で、1回ずつ処理する。
  • 同一効果の再付与時にCOUNT、STACK、VALUEをどう合成するかは、効果ごとのルールとして明文化する必要がある。
  • RATE_MODEの本格的なフレーム基準・イベント基準の切替は未実装。
  • STATEとEFFECTSのネットワーク差分同期は未実装。

8. 推奨される次段階

  1. 効果ごとに再付与規則（上書き、加算、最大値、スタック上限）を固定する。
  2. 行動制約判定を共通関数化し、MOVE、MELEE、RANGEDなどの開始時に適用する。
  3. HASTE／SLOWを移動速度・攻撃間隔へ接続する。
  4. SHIELDをダメージ受付処理の前段に接続する。
  5. STATEとEFFECTSを分離したネットワーク差分フォーマットを定義する。
